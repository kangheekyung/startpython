Chapter 1 · print 구문

화면에 글자·숫자·계산 결과를 출력하는 방법을 배워요

1-1. print() 는 화면에 보여 주는 명령어

print() 안에 출력하고 싶은 내용을 넣으면 화면에 보여 줘요. 따옴표(" ") 안은 그대로 출력되고, 숫자는 따옴표 없이 써요.

print("안녕")
→
안녕
print(7)
→
7
print(1, 2, 3)
→
1 2 3
  • 쉼표(,)로 여러 개를 넣으면 공백으로 구분돼요.
  • print는 출력한 뒤 자동으로 줄을 바꿔요.
  • 따옴표는 작은따옴표(' ')도 똑같이 사용할 수 있어요!

1-2. sep와 end 로 출력 모양 바꾸기

sep 은 값들 사이의 구분자, end 는 마지막에 붙는 글자예요.

print("a", "b", sep="-")
→
a-b
print("안녕", end="!")
→
안녕!
  • sep 기본값은 공백, end 기본값은 줄바꿈(\n)이에요.

Chapter 2 · 연산자

덧셈·뺄셈부터 나눗셈 3종류(/ · // · %)까지!

2-1. 사칙연산과 거듭제곱

파이썬은 계산도 할 수 있어요. +, -, * 는 수학 시간에 배운 그대로예요.

print(7 + 2)
→
9
print(7 * 2)
→
14
print(2 ** 3)
→
8
  • ** 는 거듭제곱이에요. 2**3 = 2×2×2 = 8

2-2. 나누기 3종류 — /, //, %

나누기는 3가지! / 는 언제나 소수, // 는 몫, % 는 나머지예요.

print(7 / 2)
→
3.5
print(7 // 2)
→
3
print(7 % 2)
→
1

2-3. 계산 순서 (괄호 → 거듭제곱 → 곱셈 · 나눗셈 → 덧셈 · 뺄셈)

괄호가 제일 먼저!

print(2 + 3 * 4)
→
14
print((2 + 3) * 4)
→
20

Chapter 3 · 변수

값을 담는 상자! 이름표 붙여 두기

3-1. 변수 = 값을 담는 상자

변수 는 값을 담아 두었다가 이름으로 다시 꺼내 쓰는 상자예요. x = 7 은 "x 라는 이름표가 붙은 상자에 7 을 넣어라" 라는 뜻!

x = 7
print(x)
→
7
name = "코딩"
print(name)
→
코딩
  • = 는 "같다" 가 아니에요! "오른쪽 값을 왼쪽에 넣어라" 라는 뜻!
  • 변수 이름은 영어 · 숫자 · _(밑줄) 로 만들고, 숫자로 시작하면 안 돼요.

3-2. 변수끼리 계산하기

여러 변수를 만들고 연산자로 계산할 수 있어요.

x = 3
y = 5
print(x + y)
→
8
name = "코딩"
print(name * 2)
→
코딩코딩

3-3. 변수 값 바꾸기

같은 변수에 새 값을 넣으면 기존 값은 잊혀져요.

a = 10
a = a + 5
print(a)
→
15
x = 7
x = x * 2
print(x)
→
14
